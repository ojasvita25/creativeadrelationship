# Ad Creative Similarity and Relationship Discovery

Pipeline for discovering and classifying pairwise relationships between display ad images from the AdImageNet dataset (`PeterBrendan/AdImageNet`). 

The system classifies creative ad relationships into six categories:
- Identical
- Containment
- Color-variant
- Text-variant
- Layout-variant
- Unrelated

## Execution Guide

### 1. Training GBDT Classifiers

To train GBDT models from pseudo-labeled candidate pairs generated by rule-based thresholds:

```bash
# Train GBDT model using Sentence Transformer text features
python train_gbdt.py --config configs/clip_sentencetransformer_rulebased.yaml --output models/gbdt_clip_sentencetransformer_classifier.pkl

# Train GBDT model using Lexical Jaccard text features
python train_gbdt.py --config configs/clip_jaccard_rulebased.yaml --output models/gbdt_clip_jaccard_classifier.pkl
```

### 2. Running Pipeline Experiments

Run end-to-end pipeline experiments with specific configuration files:

```bash
# Run GBDT Classifier with CLIP + Sentence Transformer
python main.py --config configs/clip_sentencetransformer_gbdt.yaml

# Run GBDT Classifier with CLIP + Lexical Jaccard
python main.py --config configs/clip_jaccard_gbdt.yaml

# Run Rule-based Classifier with CLIP + Sentence Transformer
python main.py --config configs/clip_sentencetransformer_rulebased.yaml

# Run Baseline Rule-based Classifier with ResNet-18 + Lexical Jaccard
python main.py --config configs/resnet18_jaccard_rulebased.yaml
```

Output HTML reports are written to the `reports/` directory as specified in each configuration file.

### 3. Generating Visualization Plots

To generate analysis plots for reports:

```bash
# Generate visual cosine similarity distributions plot (resnet_threshold: 0.73, clip_threshold: 0.61)
python -m src.utils.plot_similarity_distributions

# Generate comparative 2D decision boundary maps for GBDT models
python -m src.utils.plot_gbdt_decision_boundaries
```

Output plots are saved to:
- `reports/cosine_similarity_distributions.png`
- `reports/gbdt_2d_decision_map.png`

## Signals and Features

The classification pipeline extracts four pairwise feature signals:

| Signal | Method | Purpose |
|---|---|---|
| `visual_sim` | Cosine similarity of CLIP / ResNet-18 embeddings | Global visual & semantic similarity |
| `text_sim` | Cosine similarity (Sentence Transformer) or Jaccard overlap | Ad copy text matching |
| `color_sim` | HSV histogram correlation | Background color palette comparison |
| `phash_dist` | Hamming distance between perceptual hashes | Near-duplicate image detection |
